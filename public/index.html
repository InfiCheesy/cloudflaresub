优选IP订阅生成器

版本检查中… 发现新版本

只做三件事：导入自建节点、批量替换为优选 IP、输出可导入主流客户端的订阅链接。

适合场景

3X-UI / Xray / VPS 自建节点 + 你自己找好的 Cloudflare 优选 IP。

生成

生成订阅

粘贴节点链接、填好优选 IP / 域名，生成你的专属订阅。

重点兼容自建 VMess / VLESS / Trojan 的 WS + TLS 常见写法。

一行一个，两种写法可混写、按填写顺序合并：直接写 IP、IP:端口、域名、域名:端口（# 后面可写备注；IPv6 可填裸地址 2606:4700::1，或带端口的方括号写法 [2606:4700::1]:443）； 或写一行 https:// 链接（最多 5 个），生成时会拉取该链接的优选列表（一行一个，也支持 CSV 测速结果和 JSON 列表）并合并进来。 框里只要含链接，这条订阅就是动态的：手写行固定不变，链接部分约每小时跟随来源更新，来源暂时不可用时自动使用上次的快照，订阅不会中断。

这条订阅是哪台 VPS 的就写哪台。它会和条目一起存进 KV，还会在 KV 里生成一个 note:备注:编号 的索引键，在 Cloudflare 后台的 KV 列表里一眼就能认出是哪台机器。

给这条订阅打标签（如「香港」「主力」），方便在下方管理区按标签筛选：点下方已有标签选用，或输入新标签回车新建，每条最多 10 个；长按标签可拖动排序。 重新生成已有条目时，没动过这里就不会改动它的标签；选了标签（哪怕清空）则按这里的为准。

选“自定义天数”并填天数（1–3650）时，这条订阅会在到期后被 KV 自动删除，链接随之失效； 选“永久保存”则一直保留，直到在下方“KV 条目管理”里手动删除。同一内容重复生成时，以这次的选择为准并重新计时。

说明

  • 不会帮你找优选 IP，只负责把你现成的优选 IP 替换进节点。
  • 生成的链接是“同一份节点内容”的不同导出格式，分别给不同客户端使用。
  • 推荐勾选“保留原 Host / SNI”，这样更适合 Cloudflare CDN 场景。
  • 生成时可选永久保存，或自定义天数后由 KV 自动删除；不需要的条目也可以在页面下方的“KV 条目管理”里手动删除。
  • 订阅链接里的节点信息会通过服务端密钥加密，请不要把链接公开分享。

客户端怎么用

  • V2rayN： 用原始订阅链接
  • Shadowrocket： 用原始订阅链接
